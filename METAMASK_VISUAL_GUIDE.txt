┌─────────────────────────────────────────────────────────────┐
│  🔧 COMMON FIXES                                            │
└─────────────────────────────────────────────────────────────┘

  ❌ "Nonce too high" error
     → MetaMask → Settings → Advanced → Clear activity tab data

  ❌ Can't see network
     → Try http://localhost:8545 instead of 127.0.0.1

  ❌ Wrong network warning
     → Click network dropdown → Select "Hardhat Local"

  ❌ Connection failed
     → Check Hardhat node is running (separate PowerShell window)
     → Run: cd c:\block_Chain\votingDapp; npm run node
